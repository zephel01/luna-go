---

## 手順

1. `bash({"command": "go test ./... 2>&1"})` を実行する。

2. 全テストが PASS なら「全テストが通っています」と報告して終了。

3. 失敗がある場合:
   - エラーメッセージから失敗しているテスト名とファイルを特定する。
   - `read` ツールで該当のテストファイルとソースファイルを読む。
   - 原因を分析して修正する。
     - テスト側のバグ（期待値が間違い等）か、実装側のバグかを判断する。
     - 実装を壊さずにテストを直す場合と、実装を直してテストを通す場合を区別する。

4. 修正後に再度 `bash({"command": "go test ./... 2>&1"})` を実行する。

5. 全テストが通るまでステップ 2〜4 を繰り返す。

6. 完了したら修正内容のサマリーを報告する。

## 注意

- `go test` のタイムアウトは 30 秒。長いテストは `-timeout 120s` を付ける。
- `t.Parallel()` があるテストはレースコンディションに注意する。
- 環境依存のテスト（ファイルパス・OS・ネットワーク）は skip 判定を確認する。
- テストを削除して通すことは禁止。必ず根本原因を修正する。

## 推奨オプション

```
# 詳細出力が欲しい場合
go test -v ./... 2>&1

# 特定パッケージのみ
go test ./internal/tools/... 2>&1

# レースコンディション検出
go test -race ./... 2>&1
```
